# Пробная версия каталога для преподавателей

Для проверки формата подготовлены 12 тем из одной программы: «Практическое применение технологий информационной безопасности (+киберучения) (advance)». Это локальный образец из репозитория. Материалы из двух папок Google Drive не загружены: сетевой прокси вернул 403. Межпрограммные совпадения в этой версии ещё не проверяются.

## Что открыть

- **01_Анкета_лектора_ПРОБНАЯ.xlsx** — пустой шаблон для проверки преподавателем. Укажите ФИО, нажмите «Открыть →» для просмотра содержания, выберите «Да» или «Частично» в светло-зелёной ячейке. При частичной готовности добавьте пояснение.
- **02_Сводный_реестр_ПРИМЕР.xlsx** — пример результата объединения двух тестовых анкет. Оба лектора вымышлены; это не реальные назначения.
- **03_Предпросмотр_анкеты.png** — изображение оформления, которое можно открыть на GitHub без скачивания Excel.
- **пример ответов/** — две заполненные тестовые копии, из которых получен свод. Предназначены для демонстрации организатору.
- **источник/** — неизменённый DOCX-образец, из которого перенесено содержание. Раздел и номер темы указаны в анкете.
- **служебное/** — эталонный каталог и инструмент объединения. Преподавателю эта папка не нужна.

Содержание открывается внутри Excel-файла, поэтому интернет не требуется. Всплывающих примечаний нет. Макросов и внешних подключений нет. Можно искать темы сочетанием Ctrl+F и фильтровать таблицу по заголовкам. Для редактирования используйте Excel либо LibreOffice Calc; предварительный просмотр в мессенджере может не поддерживать ввод и переходы.

## Как собирать ответы

В общий чат отправляйте только пустой шаблон. Каждый преподаватель скачивает свою копию и возвращает заполненную анкету **лично организатору**. Свод и заполненные примеры не предназначены для общего чата.

Сохраняйте ответы в отдельную папку. После сбора их можно загрузить в чат Codex для объединения. Свод обновляется при повторном объединении, а не в реальном времени. Пустая отметка означает «не указано», не отказ. Частичная готовность в своде выделяется отдельно и требует уточнения объёма.

## Самостоятельное объединение

Нужны Python, openpyxl 3.1.5 и Pillow для логотипа. В подготовленной облачной среде они уже установлены. При установке на своей машине: `python -m pip install openpyxl==3.1.5 Pillow`.

Из папки «Пробная версия» выполните:

```bash
python 'служебное/workbooks.py' 'пример ответов' --output 'Новый_свод.xlsx'
```

Для реального сбора вместо «пример ответов» укажите папку со своими полученными анкетами. Шаблон, свод и посторонние Excel-файлы в папку ответов не кладите. Выходной файл должен иметь новое имя: уже существующий свод скрипт не перезаписывает.

Порядок строк не влияет на объединение: используются коды тем. Одинаковые копии ответа одного ФИО учитываются один раз. Если разные ответы одного ФИО конфликтуют, объединение остановится: нужно явно выбрать актуальный файл. Дата изменения файла не используется как доказательство актуальности. При ошибках в анкете новый свод не создаётся.

ФИО служит идентификатором только для прототипа. Перед полной рассылкой нужно предусмотреть отдельный код или контакт для людей с полностью совпадающими ФИО.

## Что проверить перед полной версией

1. Удобны ли ширина колонок и переход к содержанию в используемой вами программе.
2. Достаточны ли ответы «Да / Частично» и комментарий.
3. Подходит ли вид свода и фильтрация по темам, ФИО и программам.

После проверки прототипа полный каталог будет составлен из ваших программ и УТП. Если содержание одноимённой темы различается между программами, потребуются отдельные варианты и выбор применимых программ; общая отметка не должна автоматически подтверждать все разные варианты.

## Оформление Rozum

Использованы цвета из предоставленных PDF: бирюзовый `#26BBA8`, зелёный `#40B870`, графитовый `#221F1F` и белый. Логотип извлечён из `logo_dinamik.pdf`. Всплывающие примечания удалены, содержание доступно по ссылке «Открыть →». Поле «Комментарий преподавателя» оставлено для его пояснений.
