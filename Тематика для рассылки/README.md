# Тематика для рассылки

Текущий каталог находится в папке **[Готовые файлы](Готовые%20файлы/ИНСТРУКЦИЯ.md)**.

- [Анкета преподавателя](Готовые%20файлы/01_Анкета_преподавателя_Rozum.xlsx) — пустой файл для рассылки с упрощённой структурой и обновлённой ОКБО.
- [Реестр лекторов](Готовые%20файлы/02_Реестр_лекторов.xlsx) — для организатора, с фильтрами по темам, программам и ФИО.
- [Проверка источников](Готовые%20файлы/03_Проверка_источников.xlsx) — расхождения между программами и УТП.
- [Предпросмотр оформления](Готовые%20файлы/04_Предпросмотр.png).
- [Весь комплект одним ZIP](Каталог_тем_Rozum.zip).

В папке «Пробная версия» сохранён первоначальный образец на 12 темах. Для текущей рассылки предназначены файлы из «Готовые файлы».

ОКБО повторно сверена с текущими программой и УТП на Google Drive: все 32 темы имеют содержание. Устаревшие темы из прежнего УТП и пометки об отсутствующих описаниях удалены. В текущем каталоге 261 тема без повторов. Все исходные документы прочитаны с Google Drive; оригиналы не изменялись.
