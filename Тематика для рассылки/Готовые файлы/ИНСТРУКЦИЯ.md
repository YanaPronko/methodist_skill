# Каталог тем Rozum

Каталог подготовлен по программам и УТП из предоставленных папок Google Drive. ОКБО повторно сверена с текущими файлами «ОКБО_ПР_2.docx» и «ОКБО_2_УчТПл.docx»: все 32 темы имеют содержание. Связи с действующими программами и варианты содержания сохранены. Старые назначения лекторов не переносились.

## Какой файл использовать

- **01_Анкета_преподавателя_Rozum.xlsx** — один пустой файл для общего чата. Каждый преподаватель сохраняет свою копию и возвращает её организатору лично.
- **02_Реестр_лекторов.xlsx** — ваш начальный реестр. В нём весь перечень тем и программ, ФИО пока пусты. Не предназначен для общего чата.
- **03_Проверка_источников.xlsx** — отчёт по несовпадениям программы и УТП, объединённым названиям и ссылкам на все 36 документов.
- **04_Предпросмотр.png** — оформление анкеты, можно посмотреть на GitHub без скачивания Excel.
- **служебное/** — каталог данных, логотип, инструмент сборки и объединения. Преподавателю эта папка не требуется.

Цвета и логотип взяты из предоставленных образцов Rozum. Всплывающих примечаний, макросов и внешних подключений нет. Содержание встроено в Excel; ссылки на Google Drive являются дополнительным способом открыть первоисточник. Учётные записи и доступ в интернет для заполнения не нужны.

## Преподавателю

1. Скачайте файл, откройте в Excel или LibreOffice Calc.
2. Укажите ФИО полностью. Дату можно не заполнять.
3. Найдите тему поиском Ctrl+F или фильтром. Нажмите «Открыть →», чтобы прочитать содержание по программам.
4. В «Могу читать» выберите «Да» или «Частично». При ограничениях по содержанию или конкретной программе выберите «Частично» и поясните их в комментарии.
5. Сохраните файл как «Анкета_Фамилия.xlsx» и отправьте организатору **лично**. При завершении выбора поставьте «Выбор завершён».

Пустая отметка означает «не указано», а не отказ. Можно сохранить частично заполненную анкету и вернуться позже. Ответы других преподавателей в файле отсутствуют.

## Организатору

Сохраните полученные анкеты в отдельную папку. Для объединения можно загрузить их в чат Codex. Свод обновляется при объединении, не автоматически при редактировании отдельных файлов.

В реестре есть фильтры по теме, коду и полному названию программы, ФИО и готовности. Отметка относится к теме; программы показывают, где эта тема встречается. Ограничения по конкретной программе нужно уточнять по комментарию к ответу «Частично». Для тем и программ без ответов оставлены строки с пустым ФИО. Повторение темы для разных программ или разных лекторов является отдельной связью; список без повторов находится на листе «Темы».

Для самостоятельного объединения нужны Python, openpyxl 3.1.5 и Pillow:

```bash
python -m pip install openpyxl==3.1.5 Pillow
python 'служебное/catalog_tools.py' merge 'Ответы' --output 'Реестр_новый.xlsx'
```

Команды выполняются из папки «Готовые файлы». В папке «Ответы» должны быть только заполненные анкеты этой версии. Шаблон и свод туда не кладите. Инструмент не перезаписывает существующий выходной файл. Порядок строк не влияет на объединение: используются постоянные коды тем.

Одинаковые повторно присланные копии учитываются один раз. Если ответы одного человека различаются, объединение остановится: нужно явно выбрать актуальный файл. При изменённых или удалённых темах либо неверной версии анкеты новый свод не создаётся. Дата файла не используется как доказательство актуальности. Ответы сопоставляются по ФИО. Если разные преподаватели имеют полностью одинаковые ФИО, добавьте организацию в скобках в это же поле. Один человек должен указывать ФИО одинаково во всех версиях своей анкеты.

Проверки: `python 'служебное/test_catalog.py'`. Для пересборки пустых выходных файлов есть команда `python 'служебное/catalog_tools.py' build`. Она заменяет три стандартных выходных файла; не используйте её для хранения заполненных ответов.

## Особенности сопоставления

Все 32 темы актуального УТП ОКБО имеют описания в программе. Прежнее замечание об отсутствующих описаниях было связано с использованием старого УТП; эти пометки удалены.

В ПСАЭ девять тем УТП перечислены как задания трёх общих практикумов: в карточках показан общий контекст с пояснением. В одной теме ОКБО в УТП используется полное слово «киберинциденты», а в программе — сокращение «КИ»; содержание соответствует этой теме. Все особые случаи находятся в отчёте источников.

Пунктуация, регистр, пробелы и ё/е нормализованы. Варианты названий сведены к общим формулировкам; исходные названия сохранены в карточках и отчёте. «Аудит системы…» и «Система…» оставлены разными темами, поскольку у них различаются предмет и содержание.
