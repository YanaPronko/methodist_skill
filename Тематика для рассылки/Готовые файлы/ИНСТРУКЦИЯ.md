# Каталог тем Rozum

Текущая версия подготовлена по 18 программам и 18 УТП из предоставленных папок Google Drive. 329 строк УТП сведены к 265 темам. Все связи с программами и варианты содержания сохранены. Старые назначения из «Тема-Лектор_1» не переносились.

## Какой файл использовать

- **01_Анкета_преподавателя_Rozum.xlsx** — один пустой файл для общего чата. Каждый преподаватель сохраняет свою копию и возвращает её организатору лично.
- **02_Реестр_лекторов.xlsx** — ваш начальный реестр. В нём весь перечень тем и программ, ФИО пока пусты. Не предназначен для общего чата.
- **03_Проверка_источников.xlsx** — отчёт по несовпадениям программы и УТП, объединённым названиям и ссылкам на все 36 документов.
- **04_Предпросмотр.png** — оформление анкеты, можно посмотреть на GitHub без скачивания Excel.
- **служебное/** — каталог данных, логотип, инструмент сборки и объединения. Преподавателю эта папка не требуется.

Цвета и логотип взяты из предоставленных образцов Rozum. Всплывающих примечаний, макросов и внешних подключений нет. Содержание встроено в Excel; ссылки на Google Drive являются дополнительным способом открыть первоисточник. Учётные записи и доступ в интернет для заполнения не нужны.

## Преподавателю

1. Скачайте файл, откройте в Excel или LibreOffice Calc.
2. Укажите ФИО полностью. Контакт или согласованный личный код желателен для различения полных тёзок. Дату можно не заполнять.
3. Найдите тему поиском Ctrl+F или фильтром. Нажмите «Открыть →», чтобы прочитать содержание по программам.
4. В «Могу читать» выберите «Да» или «Частично». При частичной готовности поясните ограничения в комментарии.
5. В «Для каких программ» оставьте «Все», если готовы читать указанный объём во всех перечисленных программах. Либо выберите один код из списка, либо введите несколько через `;`, например `ЗИОЗ; ТЗПД`. Коды должны присутствовать в строке темы.
6. Сохраните файл как «Анкета_Фамилия.xlsx» и отправьте организатору **лично**. При завершении выбора поставьте «Выбор завершён».

Пустая отметка означает «не указано», а не отказ. Можно сохранить частично заполненную анкету и вернуться позже. Ответы других преподавателей в файле отсутствуют.

## Организатору

Сохраните полученные анкеты в отдельную папку. Для объединения можно загрузить их в чат Codex. Свод обновляется при объединении, не автоматически при редактировании отдельных файлов.

В реестре есть фильтры по теме, коду и полному названию программы, ФИО и готовности. Для тем и программ без ответов оставлены строки с пустым ФИО. Повторение темы для разных программ или разных лекторов является отдельной связью; список без повторов находится на листе «Темы».

Для самостоятельного объединения нужны Python, openpyxl 3.1.5 и Pillow:

```bash
python -m pip install openpyxl==3.1.5 Pillow
python 'служебное/catalog_tools.py' merge 'Ответы' --output 'Реестр_новый.xlsx'
```

Команды выполняются из папки «Готовые файлы». В папке «Ответы» должны быть только заполненные анкеты этой версии. Шаблон и свод туда не кладите. Инструмент не перезаписывает существующий выходной файл. Порядок строк не влияет на объединение: используются постоянные коды тем.

Одинаковые повторно присланные копии учитываются один раз. Если ответы одного человека различаются, объединение остановится: нужно явно выбрать актуальный файл. При ошибке в кодах программ, удалённых темах или неверной версии новый свод не создаётся. Дата файла не используется как доказательство актуальности. Для людей с одинаковыми ФИО используйте разные контакты или личные коды; один человек должен указывать один и тот же контакт во всех версиях своей анкеты.

Проверки: `python 'служебное/test_catalog.py'`. Для пересборки пустых выходных файлов есть команда `python 'служебное/catalog_tools.py' build`. Она заменяет три стандартных выходных файла; не используйте её для хранения заполненных ответов.

## Требует внимания перед рассылкой

В программе ОКБО не найдены отдельные описания трёх тем, присутствующих в УТП:

- «Оценка эффективности защищенности. Оценка степени зрелости компании… Аудит информационной безопасности… Тесты на проникновение»;
- «Цель и задачи XDR, его преимущества»;
- «Наглядная демонстрация рисков для предприятия на базе киберполигона при ошибках настройки СЗИ или автоматизированных систем киберцентра».

Эти темы включены в каталог с явной пометкой; содержание для них не придумано. В ПСАЭ девять тем УТП перечислены как задания трёх общих практикумов: в карточках показан общий контекст с пояснением. В нескольких темах ОКБО названия и объём УТП отличаются от программы; подобранные фрагменты явно отмечены и требуют проверки организатором. Все 19 особых случаев находятся в отчёте источников.

Пунктуация, регистр, пробелы и ё/е нормализованы. Пять вариантов названий сведены к общим формулировкам; исходные названия сохранены в карточках и отчёте. «Аудит системы…» и «Система…» оставлены разными темами, поскольку у них различаются предмет и содержание.
