# Проверка программы и УТП

Если пользователь прикрепил программу и УТП, выполни полную методическую, текстовую, арифметическую и оформительскую проверку.

## 1. Ошибки в Программе

Проверь:

- орфографию, грамматику, пунктуацию;
- лексику и стиль;
- управление, падежи, повторы;
- логико-терминологические несостыковки;
- заголовки, нумерацию разделов, подписи;
- список литературы и нормативные правовые акты;
- годы, `г.`, пробелы после `№`, тире, кавычки.

Выводи в формате:

`Было: "..."`

`Стало: "..."`

`Комментарий: ...`

## 2. Ошибки в УТП

Проверь:

- орфографию, грамматику, пунктуацию;
- регистр и заголовки;
- подписи;
- единообразие форм занятий;
- таблицу;
- итоговую строку;
- форму итоговой аттестации.

Формат: `Было → Стало`, при необходимости добавь комментарий.

## 3. Названия разделов и тем

Сравни все разделы и темы.

Если есть расхождения, выведи таблицу:

`Раздел / Тема | Как в Программе | Как в УТП | Комментарий`

## 4. Формы занятий и часы

Для каждой темы сверь:

- формы занятий;
- часы по каждой форме;
- общее количество часов;
- наличие самостоятельной работы;
- наличие форм в колонках УТП.

Формат:

`Раздел / Тема`

`Программа: формы и часы`

`УТП: формы и часы`

`В чем несоответствие`

## 5. Арифметика УТП

Проверь:

- по теме: `Всего часов` = сумма часов по формам;
- по теме: часы совпадают с программой;
- по разделу: часы равны сумме тем;
- по итоговой строке: каждый столбец равен сумме разделов или тем;
- общее количество часов совпадает с продолжительностью программы.

Выводи блоком `Арифметические и структурные несоответствия в УТП`.

## 6. Итог

В конце дай блок `ИТОГ`:

- по Программе: ошибки обнаружены / не обнаружены, ключевые типы ошибок;
- по УТП: ошибки обнаружены / не обнаружены, ключевые типы ошибок;
- по соответствию Программа ↔ УТП: принципиальные несоответствия, расхождения в часах и формах занятий, расхождения в названиях, ошибки оформления, рекомендации.

Если пользователь просит исправить, выдай исправленные `.docx` и копируемый текст отчета в чате.
