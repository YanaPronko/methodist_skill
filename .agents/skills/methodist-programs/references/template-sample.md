# Образец программы

Если пользователь не предоставил отдельный Word-шаблон, используй файл:

`assets/sample-program-ptib-advance-2026.doc`

Назначение образца:

- ориентир по титульному листу;
- ориентир по расположению грифа утверждения;
- ориентир по сведениям о разработчиках, рецензентах и рекомендации к утверждению;
- ориентир по должностям и подписям;
- ориентир по последовательности разделов;
- ориентир по оформлению блоков программы.

Правила использования:

1. Не считать этот образец темой новой программы.
2. Не копировать содержательные темы образца, если пользователь просит программу по другой теме.
3. Брать из образца только структуру, формальные блоки, должности, подписи, порядок разделов и стиль оформления.
4. Если пользователь предоставил другой шаблон или образец, он имеет приоритет над `assets/sample-program-ptib-advance-2026.doc`.
5. Если данные о должностном лице, разработчике, рецензенте или протоколе отсутствуют, использовать заполнители в квадратных скобках, а не выдумывать сведения.
6. Параметры стилей применять по `references/word-formatting.md`, если пользователь не потребовал строго перенести стили другого шаблона.
