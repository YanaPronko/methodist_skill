# Структура учебной программы

Учебная программа повышения квалификации должна включать элементы в таком порядке:

1. Титульный блок.
2. Сведения о разработчике(ах).
3. Сведения о рецензенте(ах).
4. Сведения о рекомендации к утверждению.
5. `ВВЕДЕНИЕ`.
6. `ОСНОВНЫЕ ТРЕБОВАНИЯ К РЕЗУЛЬТАТАМ УЧЕБНОЙ ДЕЯТЕЛЬНОСТИ СЛУШАТЕЛЕЙ`.
7. `ФОРМИРУЕМЫЕ КОМПЕТЕНЦИИ`.
8. `СОДЕРЖАНИЕ УЧЕБНОЙ ПРОГРАММЫ ПОВЫШЕНИЯ КВАЛИФИКАЦИИ`.
9. `МАТЕРИАЛЫ ДЛЯ ИТОГОВОЙ АТТЕСТАЦИИ`.
10. `СПИСОК РЕКОМЕНДУЕМОЙ ЛИТЕРАТУРЫ`.
11. При необходимости: `Нормативные правовые акты`.
12. Подпись должностного лица.

## Титульный блок

Включай:

- наименование вышестоящей организации;
- наименование организации-разработчика;
- гриф утверждения;
- название документа: `УЧЕБНАЯ ПРОГРАММА ПОВЫШЕНИЯ КВАЛИФИКАЦИИ`;
- полное название программы прописными буквами;
- категорию слушателей, начинающуюся со слова `Для`;
- город и год;
- сведения о разработчике(ах), рецензенте(ах), рекомендации к утверждению.

Если данных нет, используй заполнители: `[указать организацию]`, `[указать дату]`, `[указать разработчика]`, `[указать рецензента]`, `[указать номер протокола]`.

## Категория слушателей

На титульном листе:

- начинай со слова `Для`;
- разбивай длинную категорию на смысловые абзацы;
- после каждой группы, кроме последней, ставь точку с запятой;
- после последней группы ставь точку;
- не используй маркеры, тире или нумерацию.

Во введении:

- категория должна совпадать по смыслу с титульным листом;
- оформляй одной строкой или одним абзацем после формулы `Категория слушателей: ...`;
- не допускай расхождения между титульным листом и введением.

## Введение

Структура раздела:

1. Актуальность: современный контекст, важность для профессиональной деятельности, практическая значимость, нормативная база только при наличии подтвержденных данных.
2. Назначение: `Учебная программа «[название]» разработана с целью [назначение].`
3. Цель: `Цель повышения квалификации – сформировать у слушателей [итоговый образовательный результат].`
4. Задачи: `Задачи повышения квалификации:` затем список через тире. Используй 3-6 задач, начинающихся с инфинитива: ознакомить, сформировать, развить, обеспечить, изучить, закрепить, проанализировать, отработать.
5. Методы: `Методы повышения квалификации:` затем список через тире.
6. Средства: `Средства повышения квалификации: [перечень].`
7. Технические требования: включай только при необходимости.
8. Категория слушателей.
9. Продолжительность обучения.
10. Форма получения образования.
11. Виды учебных занятий.
12. Форма итоговой аттестации.

Варианты продолжительности:

- `Продолжительность обучения: [количество] академических часов.`
- `Продолжительность обучения: 1 неделя ([количество] академических часов).`
- `Продолжительность обучения: 2 недели ([количество] академических часов).`
- `Продолжительность обучения: 4 недели ([количество] академических часов).`

Не добавляй недели самостоятельно, если пользователь просит только академические часы.

Варианты формы получения образования:

- `Форма получения образования: очная (дневная).`
- `Форма получения образования: очная (дневная) с использованием информационно-коммуникационных технологий.`
- `Форма получения образования: заочная.`
- `Форма получения образования: дистанционная.`

Форма итоговой аттестации:

- `Форма итоговой аттестации – экзамен (по билетам).`
- `Форма итоговой аттестации: экзамен (тестирование).`
- `Форма итоговой аттестации: зачет.`
- `Форма итоговой аттестации: собеседование.`

## Результаты учебной деятельности

Раздел включает:

- `Профессиональная компетенция: [формулировка].`
- `Виды профессиональной деятельности:` список через тире.
- `Функции профессиональной деятельности:` список через тире.
- `Задачи, решаемые при выполнении функций профессиональной деятельности:` список через тире.

## Формируемые компетенции

Начинай фразой:

`В ходе реализации учебной программы повышения квалификации слушатель приобретёт навыки и способности, необходимые для эффективного решения задач в сфере профессиональной деятельности:`

Далее список через тире. Формулируй через знание, понимание, умение, навыки, способность, опыт, готовность.
