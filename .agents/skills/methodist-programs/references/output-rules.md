# Формат выдачи результата

## Двойная выдача обязательна

Если пользователь просит создать, отредактировать, проверить, продолжить или оформить учебную программу, УТП или аттестационные материалы, результат должен быть представлен в двух формах:

1. Готовый файл Word `.docx`, если технически возможно.
2. Полный текст в чате, пригодный для прямого копирования.
3. Отдельный текстовый файл `.txt` с тем же полным копируемым текстом, если технически возможно.

Текст в чате должен быть полным и структурированным. Не заменяй его кратким описанием, если пользователь просит копируемое изложение.

## Папка итоговых файлов

По умолчанию сохраняй итоговые файлы пользователя в:

`./итоговые`

Если пользователь указал другую папку, используй указанную им папку. Не оставляй итоговые документы только во временной или текущей рабочей папке, если пользователь явно задал папку итогов.

Для крупных задач можно создать подпапку с понятным названием внутри `./итоговые`, но в ответе обязательно дай прямые ссылки на итоговые `.docx` и текстовый файл для копирования.

## Если документ большой

Выдай файл полностью, а текст в чате раздели на части:

- `Часть 1. Титульный блок и введение`
- `Часть 2. Компетенции и содержание программы`
- `Часть 3. Материалы для итоговой аттестации`
- `Часть 4. Список литературы`
- `Часть 5. Учебно-тематический план`

## Создание программы

Ответ:

1. Краткий список принятых допущений, если данных не хватало.
2. Ссылка на готовый `.docx`.
3. Полный текст программы в чате.
4. Вопросы для финальной версии, если часть данных требует подтверждения.

## Редактирование программы

Ответ:

1. Краткий перечень найденных проблем.
2. Ссылка на исправленный `.docx`.
3. Исправленный текст или полный документ в чате.
4. Рекомендации по доработке.

## Проверка оформления

Ответ:

1. Краткий отчет об ошибках оформления.
2. Перечень исправленных элементов.
3. Ссылка на исправленный `.docx`.
4. Копируемый отчет в чате.

## Создание или продолжение УТП

Ответ:

1. Ссылка на готовый `.docx`.
2. УТП в табличной форме в чате.
3. Проверка совпадения тем, форм занятий и часов с программой.
4. Список добавленных и исправленных строк.

## Проверка Программы и УТП

Ответ с блоками:

1. `Ошибки в Программе`.
2. `Ошибки в УТП`.
3. `Несоответствия названий разделов и тем`.
4. `Несоответствия форм занятий и часов по темам`.
5. `Арифметические и структурные несоответствия в УТП`.
6. `ИТОГ`.
7. Ссылки на исправленные `.docx`, если создавались.
