# Учебно-тематический план

Создавай УТП по структуре учебной программы.

## Обязательные элементы

1. Титульный блок.
2. Название документа:

`УЧЕБНО-ТЕМАТИЧЕСКИЙ ПЛАН`

`повышения квалификации`

3. Полное название программы прописными буквами.
4. Продолжительность обучения.
5. Форма получения образования.
6. Таблица распределения часов.
7. Форма итоговой аттестации.
8. Подпись должностного лица.

## Таблица УТП

В таблице должны быть колонки, если они предусмотрены шаблоном или содержанием программы:

- `№ п/п`;
- `Наименования разделов, модулей, тем`;
- `Количество учебных часов всего`;
- `Лекции`;
- `Практические занятия`;
- `Семинарские занятия`;
- `Круглые столы, тематические дискуссии и др.`;
- `Лабораторные занятия`;
- `Деловые игры`;
- `Тренинги`;
- `Самостоятельная работа`;
- `Стажировка`;
- `Кафедра` или `Цикловая комиссия`, если есть в шаблоне.

Если в начатом УТП уже есть другой состав колонок, сохраняй его и заполняй соответствующие колонки.

## Сверка с программой

Проверь:

- название программы совпадает полностью;
- форма получения образования совпадает;
- продолжительность обучения совпадает;
- форма итоговой аттестации совпадает;
- названия разделов совпадают;
- названия тем совпадают;
- нумерация разделов и тем совпадает;
- часы по каждой теме совпадают с часами в скобках после темы программы;
- формы занятий совпадают с формами в программе;
- самостоятельная работа отражена в отдельной колонке;
- для дистанционной формы соблюдено 80/20;
- есть итоговая строка `ВСЕГО:`;
- итоговая строка содержит суммы по всем видам занятий.

## Заполнение строк

Для каждой темы из программы:

1. Сложи часы по формам занятий в общее количество.
2. Внеси часы в соответствующие колонки.
3. Не добавляй формы занятий, которых нет в программе.
4. Если форма занятия есть в программе, но в УТП нет подходящей колонки, используй ближайшую колонку только при очевидном соответствии; иначе сообщи пользователю.
5. Строки разделов должны суммировать строки тем раздела, если такой формат принят в шаблоне.
6. Итоговая строка должна суммировать строки разделов или все темы, в зависимости от структуры шаблона.
