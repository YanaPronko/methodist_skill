# Продолжение начатого УТП

Используй этот сценарий, когда пользователь загружает учебную программу и уже начатый учебно-тематический план, который нужно продолжить.

## Алгоритм

1. Извлеки из программы:

- полное название;
- продолжительность обучения;
- форму получения образования;
- форму итоговой аттестации;
- названия разделов;
- темы внутри каждого раздела;
- формы занятий и часы по каждой теме.

2. Проанализируй начатый УТП:

- структуру документа;
- состав колонок таблицы;
- стиль нумерации разделов и тем;
- уже внесенные разделы и темы;
- последнюю корректно заполненную строку;
- отсутствующие темы;
- расхождения между уже заполненной частью и программой.

3. Продолжи УТП:

- добавь недостающие разделы и темы;
- сохрани оформление, стиль таблицы, шрифт, интервалы, ширину колонок и структуру начатого УТП;
- внеси общее количество часов;
- распредели часы по соответствующим колонкам форм занятий;
- не меняй корректно заполненные строки без необходимости;
- исправляй очевидные ошибки в часах, формах занятий и названиях, если они прямо противоречат программе;
- если исправление спорное, оставь отчет и запроси подтверждение.

4. Пересчитай:

- часы по каждой теме;
- часы по каждому разделу;
- часы по каждой форме занятий;
- общую продолжительность;
- итоговую строку `ВСЕГО`.

5. Проверь соответствие:

- название программы;
- продолжительность;
- форма получения образования;
- форма итоговой аттестации;
- названия разделов и тем;
- часы и формы занятий.

## Итог ответа

Всегда выдай:

- готовый продолженный файл Word `.docx`, если технически возможно;
- полную текстовую версию УТП в чате, пригодную для копирования;
- краткий список добавленных строк;
- краткий список исправленных строк;
- предупреждения о спорных местах или данных, требующих подтверждения.

Пример формата:

`Добавлено: раздел II, темы 1-4; раздел III, темы 1-3; итоговая строка ВСЕГО.`

`Исправлено: в теме 2 раздела I распределение часов приведено к программе.`
